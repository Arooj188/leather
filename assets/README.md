# Homepage Hero Image

The homepage image is `leather main.png`. `index.html` references it directly with the relative path `assets/leather main.png`.

The project-relative asset path resolves on GitHub Pages to `/leather/assets/leather%20main.png`. Keep the image optimized for web delivery.

If the image is unavailable, the homepage displays a labelled neutral fallback. Do not replace it with a generic product photo or external image URL.
